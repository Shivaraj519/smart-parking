1. GROUP BY, HAVING & Aggregate Functions

Groups parking slots by facility and vehicle type, calculates slot totals, and filters only groups with capacity ≥ 2 via HAVING.

SELECT pa.area_name, ps.supported_vehicle_type,
       COUNT(ps.slot_id) AS total_slots,
       SUM(CASE WHEN ps.slot_status = 'AVAILABLE' THEN 1 ELSE 0 END) AS free_slots
FROM Parking_Areas pa
INNER JOIN Parking_Slots ps ON pa.area_id = ps.area_id
GROUP BY pa.area_name, ps.supported_vehicle_type
HAVING total_slots >= 2
ORDER BY total_slots DESC;

2. Multi-Table Relational JOINs

Demonstrating INNER JOIN across Users, Vehicles, Reservations, Slots, and Areas with dynamic tariff calculation.

SELECT u.full_name, v.license_plate, r.booking_code,
       pa.area_name, s.slot_number, r.estimated_cost
FROM Reservations r
INNER JOIN Users u ON r.user_id = u.user_id
INNER JOIN Vehicles v ON r.vehicle_id = v.vehicle_id
INNER JOIN Parking_Slots s ON r.slot_id = s.slot_id
INNER JOIN Parking_Areas pa ON s.area_id = pa.area_id
WHERE r.booking_status IN ('CONFIRMED', 'CHECKED_IN')
LIMIT 5;

3. Subqueries (Nested & Correlated)

Finds drivers whose cumulative spending exceeds the overall average user expenditure using a nested subquery.

SELECT u.user_id, u.full_name, u.email,
       (SELECT COALESCE(SUM(amount), 0) FROM Payments p WHERE p.user_id = u.user_id) AS total_spent
FROM Users u
WHERE (SELECT COALESCE(SUM(amount), 0) FROM Payments p WHERE p.user_id = u.user_id) >
      (SELECT AVG(amount) FROM Payments)
ORDER BY total_spent DESC;

4. Views, ACID Transactions & Triggers

Summarizing data through predefined SQL View view_available_slots_summary and automated triggers.

SELECT area_name, supported_vehicle_type, total_slots,
       available_slots, occupied_slots, base_hourly_rate
FROM view_available_slots_summary
WHERE available_slots > 0
LIMIT 5;
